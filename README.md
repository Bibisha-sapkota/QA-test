This project presents manual testing of the OrangeHRM Demo web application.

Project Goal
The goal of this project is to demonstrate basic manual testing skills, including test planning, test case design and bug reporting

Application Under Test
Name: OrangeHRM Demo
URL: https://opensource-demo.orangehrmlive.com/
Type: Web application (HR Management System)


Test Scope
The following functionalities were tested:

Login and logout
User authentication and authorization
Form validations
Add Employee functionality
Basic navigation between pages
Error messages and success feedback


Test Types
Manual testing
Functional testing
Smoke testing
Basic regression testing



Test Artifacts
This project contains the following documents:
Test Plan
Test Cases
RTm
Bug Reports


Tools
Web browser (Google Chrome)
Manual testing techniques
